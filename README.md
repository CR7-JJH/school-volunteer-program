# Daeyoung-club-matching-system

학생들의 관심사와 활동 성향을 바탕으로 잘 맞는 동아리를 연결해주는 학교 봉사 프로젝트입니다.

## 현재 구성

| 경로 | 설명 |
| --- | --- |
| `survey/` | 동아리 매칭 **사전 설문** 페이지 (정적 웹페이지) |
| `survey/questions.js` | 설문 문항 정의 — 문항 추가·수정은 이 파일만 고치면 됩니다 |
| `survey/config.js` | 응답 전송 주소, 마감 안내 등 운영 설정 |
| `apps-script/Code.gs` | 응답을 Google 스프레드시트에 저장하는 수집 스크립트 |

## 사전 설문 구성

1. **기본 정보** — 학년, 반, 번호, 이름
2. **관심 분야와 진로** — 관심 분야(최대 3개), 희망 진로 계열, 희망 직업
3. **활동 성향** — 협업·활동성·창작·탐구·봉사·리더십 5점 척도, 선호 활동 방식, 참여 가능 시간
4. **기대와 경험** — 동아리에서 얻고 싶은 것(최대 2개), 이전 동아리 경험, 새 동아리 아이디어
5. **제출 전 확인** — 개인정보 수집·이용 동의

기능: 단계별 진행 표시, 필수 항목·입력 범위 검사, 작성 중 내용 자동 저장(이어서 작성하기), 모바일·다크 모드 지원.

## 로컬에서 보기

`survey/index.html` 파일을 브라우저로 열면 됩니다. 별도 설치가 필요 없습니다.

`config.js`의 `submitUrl`이 비어 있으면 **테스트 모드**로 동작합니다. 응답은 해당 브라우저에만 저장되며,
완료 화면에서 JSON 파일로 내려받을 수 있습니다.

## 응답을 Google 스프레드시트로 받기

1. Google 스프레드시트를 새로 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `apps-script/Code.gs` 내용을 붙여넣고 저장합니다.
3. **배포 → 새 배포 → 유형: 웹 앱**을 선택합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
4. 발급된 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 `survey/config.js`의 `submitUrl`에 넣습니다.
5. 설문을 한 번 제출해 스프레드시트의 `응답` 시트에 행이 추가되는지 확인합니다.

배열 응답(관심 분야 등)은 `it, science`처럼 쉼표로 이어서 저장되며, 문항을 추가하면 열이 자동으로 늘어납니다.

## 배포 (GitHub Pages)

저장소 **Settings → Pages**에서 브랜치를 선택하고 루트(`/`)로 배포하면
`https://<계정>.github.io/Daeyoung-club-matching-system/` 주소로 설문에 접속할 수 있습니다.
