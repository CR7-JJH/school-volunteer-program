# 분리배출 디버깅 프로젝트

> 우리 학교 쓰레기통 속 '오류'를 찾아라
> **버리기 전 3초 if문: 비웠나? 헹궜나? 뗐나? → 재활용 TRUE**

대영고 2학기 R&A 사회 참여 봉사 활동(캠페인)의 웹 도구 모음입니다.
1·2학년 분리수거함의 혼입률을 낮추고, 그 효과를 데이터로 입증하는 것이 목표입니다.

## 구성

| 경로 | 설명 |
| --- | --- |
| `checker/` | **분리배출 판별 알고리즘 QR 웹페이지** (계획서 솔루션 ①) |
| `checker/items.js` | 품목별 판별 조건(if문)·결과·팁 정의 |
| `checker/poster.html` | 분리수거함용 QR 안내판·순서도 스티커 인쇄 페이지 (솔루션 ②) |
| `survey/` | 사전·사후 **인식 변화 설문** 페이지 (정적 웹페이지) |
| `survey/questions.js` | 설문 문항·퀴즈 정답·해설 정의 — 문항 수정은 이 파일만 고치면 됩니다 |
| `survey/config.js` | 응답 전송 주소, 기본 설문 종류, 마감일 등 운영 설정 |
| `apps-script/Code.gs` | 응답을 Google 스프레드시트에 저장하는 수집 스크립트 |

## 기간별 공개 설정 (`site-config.js`)

학생들이 지금 참여할 활동만 보이도록 `site-config.js`의 `open` 값으로 켜고 끕니다.

| 날짜 | preSurvey | checker | postSurvey |
| --- | :-: | :-: | :-: |
| 11/4 ~ 11/9 사전 설문 | `true` | `false` | `false` |
| 11/10 ~ 11/12 | `false` | `false` | `false` |
| 11/13 ~ 11/24 캠페인 | `false` | `true` | `false` |
| 11/25 ~ 11/27 사후 설문 | `false` | `true` | `true` |

- `false`인 활동은 첫 화면에서 숨겨지고, 주소로 직접 들어와도 안내 문구만 보입니다.
- 팀원 확인용: 주소 끝에 `?preview=1`을 붙이면 닫힌 페이지도 열립니다. 미리보기에서는 응답·판별 기록이 저장되지 않습니다.
  - 판별기 미리보기: `.../checker/?preview=1`
  - 사후 설문 미리보기: `.../survey/?phase=post&preview=1`
- QR 인쇄 페이지(`checker/poster.html`)는 항상 열려 있습니다.

## 판별 웹페이지 (계획서 솔루션 ①)

주소: https://cr7-jjh.github.io/school-volunteer-program/checker/

물건을 고르면 1학기 조건문 알고리즘 순서대로 예/아니오 질문을 합니다.

```
if (비웠나?) → if (헹궜나?) → if (뗐나?) → if (재질은?) → return 버리는 곳
```

- 품목 17개 + **목록에 없는 물건**(분리배출 표시로 재질을 고른 뒤 공통 조건 확인)
- 결과 화면에 버리는 곳, 버리기 전에 할 일, 'if문 실행 기록'을 보여줍니다.
- 판별 기준은 사전·사후 설문 퀴즈의 정답과 같습니다. 퀴즈 8문항 모두 같은 결론이 나오는지 테스트했습니다.
- 품목·질문을 고치려면 `checker/items.js`만 수정하면 됩니다.

### 가장 많이 틀린 TOP 5 표시 (11/9 이후)

사전 혼입률 측정 분석이 끝나면 `checker/config.js`의 `top5`에 품목 id를 많이 틀린 순서로 넣으세요.
판별기 첫 화면 맨 위에 순위와 함께 표시됩니다.

품목 id: `pet` 페트병, `cup` 테이크아웃 컵, `lunchbox` 도시락·배달 용기, `milk` 우유팩, `papercup` 종이컵,
`can` 음료캔, `snack` 과자·젤리 봉지, `vinylbag` 비닐봉지, `cupnoodle` 컵라면 용기, `styrofoam` 스티로폼 완충재,
`paper` 프린트물·종이, `note` 스프링 노트, `receipt` 영수증, `pen` 볼펜·문구류, `straw` 빨대·일회용 숟가락,
`tissue` 휴지·물티슈, `glass` 유리병

### QR 안내판·스티커 인쇄

`checker/poster.html`을 열고 분리수거함 위치를 한 줄에 하나씩 적은 뒤 인쇄합니다.

- **A4 안내판:** '버리기 전 3초 if문' 순서도와 QR이 들어가요. 한국어와 영어를 함께 적었어요.
- **순서도 스티커:** A4 한 장에 8개가 들어가요. 투입구 옆에 붙이는 용도예요.
- QR마다 `?from=위치`가 붙어서, 어느 분리수거함에서 QR을 많이 찍었는지 기록됩니다.

### 접속 수 기록 (효과 측정 ④)

`checker/config.js`의 `logUrl`에 설문과 같은 Apps Script 주소를 넣으면, 접속과 판별 결과가 `판별기록` 시트에 쌓입니다.
기록 항목은 시각, 접속/판별, 위치, 품목, 결과, 할 일 개수이며 개인정보는 기록하지 않습니다.

## 설문 (계획서 '효과 측정 계획' ③)

사전·사후에 **같은 문항**으로 실시해 전후를 비교합니다. 익명이며 학번·이름은 수집하지 않습니다.

| 단계 | 내용 | 사전 | 사후 |
| --- | --- | :-: | :-: |
| 시작하기 | 학년 | ✓ | ✓ |
| 판별 퀴즈 ①② | 분리배출 판별 퀴즈 8문항 (+ '잘 모르겠어요') | ✓ | ✓ |
| 실천 의지 | 5점 척도 4문항 | ✓ | ✓ |
| 평소 습관 | 헷갈리는 품목(최대 3개), 어려운 이유 | ✓ | ✓ |
| 캠페인 참여 | '작은 약속' 보드 참여 여부, 소감 | | ✓ |

- **사전 설문:** https://cr7-jjh.github.io/school-volunteer-program/survey/
- **사후 설문:** https://cr7-jjh.github.io/school-volunteer-program/survey/?phase=post

(GitHub Pages를 켠 뒤부터 열립니다.)

퀴즈 문항은 계획서의 오류 유형에 맞춰 분류되어 있고, 유형별 점수가 함께 저장됩니다.

판별기와 퀴즈 정답은 **우리 학교 수거함 기준**을 따릅니다.

| 물건 | 버리는 곳 |
| --- | --- |
| 종이팩 (우유팩·종이컵) | 종이 수거함 |
| 스티로폼 (컵라면 용기·완충재) | 일반쓰레기 |
| 캔·고철 (노트 스프링 등) | 캔 수거함 |

| 유형 | 문항 |
| --- | --- |
| 세척 (비웠나? 헹궜나?) | 2 컵라면 용기, 4 우유팩 |
| 라벨·부착물 (뗐나?) | 1 페트병, 8 스프링 노트 |
| 재질 혼동 | 3 테이크아웃 컵, 5 영수증, 6 과자 봉지, 7 볼펜 |

- 사전 설문에서는 정답을 보여주지 않습니다. 정답을 보여주면 그 자체가 개입이 되어 전후 비교가 흐려지기 때문입니다.
  완료 화면에서는 QR 판별 페이지를 안내합니다.
- 사후 설문은 제출 직후 점수와 정답·해설을 보여줍니다.
- 사후 설문의 `promiseBoard`(약속 보드 참여 여부)로 참여자와 비참여자의 실천 의지 점수를 비교할 수 있습니다.
  일관성의 법칙 효과를 검증하는 데 씁니다.

> ⚠️ 사전 설문을 배포한 뒤에는 문항 `id`와 퀴즈 내용을 바꾸지 마세요. 사후와 비교할 수 없게 됩니다.

## 로컬에서 보기

`survey/index.html`을 브라우저로 열면 됩니다. 별도 설치가 필요 없습니다.

`config.js`의 `submitUrl`이 비어 있으면 **테스트 모드**입니다. 응답은 해당 브라우저에만 저장되며,
완료 화면에서 JSON으로 내려받을 수 있습니다.

## 응답을 Google 스프레드시트로 받기

1. Google 스프레드시트를 새로 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `apps-script/Code.gs` 내용을 붙여넣고 저장합니다.
3. **배포 → 새 배포 → 유형: 웹 앱**을 선택합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
4. 발급된 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 `survey/config.js`의 `submitUrl`과
   `checker/config.js`의 `logUrl`에 넣습니다.
5. 설문을 한 번 제출해 응답이 들어오는지 확인합니다. 사전 응답은 `사전` 시트, 사후 응답은 `사후` 시트에 쌓입니다.
   확인용 응답은 지워 주세요.

시트에는 `퀴즈점수`, `세척_정답`, `라벨_정답`, `재질_정답` 열이 자동으로 들어갑니다.

### 분석 탭

응답 시트 맨 앞의 `분석` 탭이 수식으로 자동 계산합니다. 응답이 들어오면 바로 갱신돼요.

1. 요약: 응답 수, 퀴즈 평균·정답률, 유형별(세척·라벨·재질) 정답률, 실천 의지 — 사전·사후·변화
2. 가장 많이 틀린 문항 TOP 3 (사전)
3. 문항별 오답률 (사전·사후·변화)과 가장 많이 고른 오답
4. 학생들이 헷갈린다고 고른 물건 순위
5. 분리배출이 어려운 이유 순위
6. 작은 약속 보드 참여자 vs 미참여자 (일관성의 법칙 검증)
7. QR 판별기 접속·판별 수, 많이 판별한 물건, QR 위치별 접속

- '잘 모르겠어요'는 오답으로 계산합니다.
- 제출시각이 빈 줄은 계산에서 빠집니다. 응답을 지울 때는 칸이 아니라 **행 전체를 삭제**하세요.
- 숨겨진 열(J~K, P~V)은 계산용이니 지우지 마세요.

## 배포 (GitHub Pages)
