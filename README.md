# 분리배출 디버깅 프로젝트

> 우리 학교 쓰레기통 속 '오류'를 찾아라
> **버리기 전 3초 if문: 비웠나? 헹궜나? 뗐나? → 재활용 TRUE**

대영고 2학기 R&A 사회 참여 봉사 활동(캠페인)의 웹 도구 모음입니다.
1·2학년 분리수거함의 혼입률을 낮추고, 그 효과를 데이터로 입증하는 것이 목표입니다.

## 구성

| 경로 | 설명 |
| --- | --- |
| `survey/` | 사전·사후 **인식 변화 설문** 페이지 (정적 웹페이지) |
| `survey/questions.js` | 설문 문항·퀴즈 정답·해설 정의 — 문항 수정은 이 파일만 고치면 됩니다 |
| `survey/config.js` | 응답 전송 주소, 기본 설문 종류, 마감일 등 운영 설정 |
| `apps-script/Code.gs` | 응답을 Google 스프레드시트에 저장하는 수집 스크립트 |

## 설문 (계획서 '효과 측정 계획' ③)

사전·사후에 **같은 문항**으로 실시해 전후를 비교합니다. 익명이며 학번·이름은 수집하지 않습니다.

| 단계 | 내용 | 사전 | 사후 |
| --- | --- | :-: | :-: |
| 시작하기 | 학년 | ✓ | ✓ |
| 판별 퀴즈 ①② | 분리배출 판별 퀴즈 8문항 (+ '잘 모르겠어요') | ✓ | ✓ |
| 실천 의지 | 5점 척도 4문항 | ✓ | ✓ |
| 평소 습관 | 헷갈리는 품목(최대 3개), 어려운 이유 | ✓ | ✓ |
| 캠페인 참여 | '작은 약속' 보드 참여 여부, 소감 | | ✓ |

- **사전 설문 주소:** `.../survey/`
- **사후 설문 주소:** `.../survey/?phase=post`

퀴즈 문항은 계획서의 오류 유형에 맞춰 분류되어 있고, 유형별 점수가 함께 저장됩니다.

| 유형 | 문항 |
| --- | --- |
| 세척 (비웠나? 헹궜나?) | 2 컵라면 용기, 4 우유팩 |
| 라벨·부착물 (뗐나?) | 1 페트병, 8 스프링 노트 |
| 재질 혼동 | 3 테이크아웃 컵, 5 영수증, 6 과자 봉지, 7 볼펜 |

- 사전 설문에서는 정답을 보여주지 않습니다. 정답을 보여주면 그 자체가 개입이 되어 전후 비교가 흐려지기 때문입니다.
  완료 화면에서는 QR 판별 페이지를 안내합니다.
- 사후 설문은 제출 직후 점수와 정답·해설을 보여줍니다.
- 사후 설문의 `promiseBoard`(약속 보드 참여 여부)로 참여자와 비참여자의 실천 의지 점수를 비교할 수 있습니다.
  일관성의 법칙 효과를 검증하는 데 씁니다.

> ⚠️ 사전 설문을 배포한 뒤에는 문항 `id`와 퀴즈 내용을 바꾸지 마세요. 사후와 비교할 수 없게 됩니다.

## 로컬에서 보기

`survey/index.html`을 브라우저로 열면 됩니다. 별도 설치가 필요 없습니다.

`config.js`의 `submitUrl`이 비어 있으면 **테스트 모드**입니다. 응답은 해당 브라우저에만 저장되며,
완료 화면에서 JSON으로 내려받을 수 있습니다.

## 응답을 Google 스프레드시트로 받기

1. Google 스프레드시트를 새로 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `apps-script/Code.gs` 내용을 붙여넣고 저장합니다.
3. **배포 → 새 배포 → 유형: 웹 앱**을 선택합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
4. 발급된 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 `survey/config.js`의 `submitUrl`에 넣습니다.
5. 설문을 한 번 제출해 응답이 들어오는지 확인합니다. 사전 응답은 `사전` 시트, 사후 응답은 `사후` 시트에 쌓입니다.
   확인용 응답은 지워 주세요.

시트에는 `퀴즈점수`, `세척_정답`, `라벨_정답`, `재질_정답` 열이 자동으로 들어갑니다.
퀴즈 정답률의 전후 비교는 두 시트의 `퀴즈점수` 평균을 비교하면 됩니다.

## 배포 (GitHub Pages)

1. 저장소 **Settings → Pages**에서 브랜치를 선택하고 루트(`/`)로 배포합니다.
2. `https://<계정>.github.io/<저장소>/survey/` 주소를 QR코드로 만들어 배포합니다.
